# Ruthless Clarity — Framework
**Source protocol:** *Ruthless Clarity* by Cameron Hartis. This file does not use chapter numbers.  
**This file is the protocol.** It does not load a personal profile.  
**Updated:** 2026-09-29

IN = Victory. DO = tightening loop (Map + CV + Kill) then Needle → Bet → Lock. OUT = Verify → Rollback or Double-down → Codify → Teach → Live.

Gates: Victory, Fact-check, Map, CV, Kill, Needle, Bet, Lock, Verify, Rollback, Double-down, Codify, Teach, Live.

Load `SKILL.md` first. Open this file only for required I/O on a gate.

---

## Fact-check

Mark each material claim **Intended** (why the page/policy/model answer exists and what it was trying to make true) or **Observed** (floor, log, running system) or **Unknown**. Do not promote Unknown to Observed.

If they disagree, recover intent first. Then classify:
- **Floor workaround** — intent was sound; practice left the page.
- **Page drift** — page wrong, stale, or written without understanding the system.
Both must stand scrutiny. Do not translate this as “documentation lies, ignore it.”

---

## Victory

Victory is a verifiable state, not a feeling, date, or “ready.”

**Outsider test:** someone who does not do this work can score won/lost from the stated outcome with no interpretation. No kinship or age metaphors.

In: name of the situation; what is being attempted.  
Out: one-sentence state; check method; outsider wording; unknowns/risks; if-not-met; locked = yes.

Nothing else starts until locked.

---

## Tightening loop (Map + CV + Kill, one commit)

Reason across map, lever, and kills together. Commit one package when the loop is stable, not when the map is complete. Incomplete maps are intended.

**Map.** Recover the intention behind the documentation, then compare to the floor. A mismatch is either a workaround or page drift. Scrutinize both. Handoffs, workarounds, gates, false owners. Segment 3–7 only if still wide. In: locked Victory + process. Out: segments that matter; junctions + real owners; undocumented steps; variable inventory; each disagreement labeled workaround or page drift.

**CV.** One rate/volume/action changeable this afternoon. Not outcome, hope, market, “whether.” In: Victory + forming map. Out: symptom; inventory (protect nothing); upstream chain; CV; afternoon proof; why it moves Victory; any variable that was being protected.

**Kill.** Constraints first. Fail → log → dead. In: Victory + map + CV. Out: constraints; kill log (option → constraint → Y/N); survivors; anything almost carried. Empty log invalid. Session kills persist unless full rejustification.

---

## Needle

One metric causally tied to Victory and CV. If it can move without Victory moving, discard it.  
Out: metric; target; check method; causal sentence.

---

## Bet

A real action, smaller than fear, that produces information.  
**Irreversible** = the spend and the information cannot be un-had. It does **not** mean the system change can never be unwound.  
Write the unwind rule in the bet. Small is what keeps unwind cheap. Analysis-only “bets” fail this gate.

Out: bet; expected needle move; unwind / rollback condition; time box.  
Then **run it** and record result. Plan alone does not unlock Lock. The result is paid for even if you later unwind.

---

## Lock

Cut once on the information the bet produced. Reopen the *decision* only with written authorization.  
Lock is not a ban on unwinding the *position* after Verify misses.  
In: bet **results**. Out: locked statement; reopen protection; owner of the lock.

---

## Verify

Implementation is not victory. Needle vs target, binary. Feeling better is not a check.  
Out: measured value; met / not met; evidence.

---

## Rollback or Double-down

Not met → unwind the position using the rule written in the Bet; stop compounding.  
Met → increase exposure faster than comfort.  
Rollback does not refund the bet and does not revive permanent kills. It prevents a failed cut from becoming the new default.  
Out: binary; next action.

Bet spends for information. This gate decides whether that position grows or comes off.

---

## Codify

Only after met + double-down. Lesson lives in the system so the same person is not required.  
Out: one-sentence lesson; where it lives; drift control; killed recurrence; signal the system remembers.

---

## Teach

Real when others can run it without the author. If every hard call still routes through one person, that person is the hidden CV.  
Out: transfer artifact; killed deferrals; signal others can run the relevant slice.

---

## Live

Claimed vs actual on the last real moment, including agent output. If it only works when watched, it is a performance.  
Out: claimed vs done; gap; correction; same standard in private as in public.

---

## Agent start

1. This framework + `SKILL.md` only. Do not fetch a personal profile.
2. Lock Victory (outsider test).
3. Tightening loop → one diagnostic package.
4. Fact-check every claim. Recover doc intent before declaring the page a lie.
5. Needle → Bet → result → Lock → Verify → Rollback or Double-down → Codify.
6. Hard gates. No invented upstream artifacts. CV must pass the afternoon test. Do not read irreversible as never-unwind. Do not navigate by chapter numbers.
